# Bus Data — Passenger Analysis
This project is an exploratory and inferential data analysis of passenger behavior on a regional bus route from Nové Zámky to Nitra. The dataset was collected through direct observation during a morning service and contains demographic, behavioral, and travel-related attributes of individual passengers.

## Project Goal
The aim of the analysis is to understand patterns in passenger behavior and examine relationships between demographic factors (age, student status), travel characteristics (distance, duration), and behavioral indicators (mobile device usage, luggage weight).

## Data
The dataset includes the following key variables:

- age group and student status
- ticket type (discounted vs. full fare)
- origin and destination stops
- time spent on the bus and travel distance
- luggage weight
- level of mobile device engagement during travel

## Methods
The analysis combines:

- Exploratory Data Analysis (EDA)
- Data visualization (histograms, boxplots, count plots)
- Statistical hypothesis testing:
- Normality and variance checks (Shapiro–Wilk, Levene’s test)

## Tools & Technologies
- Python (pandas, numpy, scipy, matplotlib, seaborn)
- Statistical analysis and hypothesis testing
- Jupyter Notebook
